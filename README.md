# Hi, I'm Jordan

iOS and macOS developer with three years of professional experience. Right now I'm working on a CS degree at WGU. I like building polished native apps and I like understanding how the platforms underneath them work.

## What I'm working on

- **[SwiftNES](https://github.com/mazjap/swiftnes)**: an NES emulator written entirely in Swift. The 6502 CPU, PPU, and IO are done. The APU and additional mappers are what's left.
- **[Developer portfolio](https://github.com/mazjap/Portfolio-Attempt-20)**: a three-part system with a Vite + React + TypeScript frontend, a Node/Express API, and **[Folio](https://github.com/mazjap/Folio-App)**, a native SwiftUI content manager that feeds it.
- **[Hailey60](https://github.com/mazjap/Hailey60)**: a hand-wired split keyboard on RP2040-Zero controllers, with full-duplex UART over TRRS. Firmware is finished and I'm planning on submitting it to QMK.
